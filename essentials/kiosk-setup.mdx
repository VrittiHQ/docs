# Provisioning the Kiosk

To set up the Vritti Lens biometric kiosk in your facility:

1. Download the APK from your Vritti Dashboard.
2. Install the APK on your Android tablet.
3. Authenticate using the one-time facility PIN generated from your admin panel.

## Offline Mode
The kiosk automatically queues attendance events locally if the internet drops, and syncs them securely to the cloud when the connection is restored using UUID idempotency.
