# Welcome to Vritti

Vritti is an AI-native staff tracking and workforce management platform built for modern educational institutions and enterprises across India. It unifies biometric face recognition, selfie with GPS geofencing, shift scheduling, leave approvals, and automated payroll into a single operational system.

## Core Capabilities

### Biometric Attendance Engine
Vritti Lens uses AI face embeddings combined with 3-frame liveness detection to record attendance in under 1 second per employee. It operates offline with automatic background synchronization.

### Event-Sourced Audit Ledger
Every attendance punch or kiosk scan creates an immutable event record. Daily summaries are calculated automatically, eliminating manual register errors.

### Indian Statutory Payroll Compliance
Automate monthly payroll calculations with pre-configured rules for Employees' Provident Fund (EPF), Employees' State Insurance (ESI), Professional Tax (PT), and Tax Deducted at Source (TDS).

### Granular Role-Based Access Control
Enforce institutional security using built-in standard roles (Super Admin, Admin, HR, Manager, Staff) or create custom role profiles with fine-grained permission bitmasks.
